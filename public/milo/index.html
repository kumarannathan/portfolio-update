The screens

One control room.

Your keys, your server

There is no Milo cloud in the middle.

Milo is one process you run. API keys are stored on your server, sent only to the service they belong to, and never returned to the browser in full.

  • Each account gets its own workspace. Email + password, or plug in Supabase Auth.
  • Export everything as JSON at any time. Keys are left out.
  • Try the whole pipeline on sample data first. No keys needed.
  • MIT. Read every line before it touches your inbox.
Get Milo

Download, drag to Applications, open.

Milo for Mac runs the whole thing in one app: the agents, the control room, your workspace. First launch walks you through naming a workspace, connecting a model and describing what you sell. Or start with sample data and connect keys later.

Download for Mac Coming soonSource on GitHub

The Mac app is signed and notarized by Apple, so it opens like any other download. macOS 12 or later, Apple silicon and Intel.

Or run it yourself
$ git clone https://github.com/kumarannathan/Milo.git
$ cd Milo && npm install
$ npm run build
$ npm start   # then open localhost:4400

The server version adds accounts, so a team can share one deployment. Node 20 or later.
