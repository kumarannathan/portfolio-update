Why it's trustworthy

Every run, tool call, token and dollar is visible.

An inbox, not a firehose

Emails, replies and meeting invites queue up for you. Raise the autonomy level only when you trust it.

Your connections

Agents ask for an action, like "find people". You choose which connection does it: Apollo, Hunter, Tavily, HubSpot, Cal.com, your inbox.

Receipts for everything

Duration, tokens and cost per run. Status code and latency per tool call. A feed you can watch instead of guessing.

The screens

One control room.

Your keys, your server

There is no Milo cloud in the middle.

Milo is one process you run. API keys are stored on your server, sent only to the service they belong to, and never returned to the browser in full.

  • Each account gets its own workspace. Email + password, or plug in Supabase Auth.
  • Export everything as JSON at any time. Keys are left out.
  • Try the whole pipeline on sample data first. No keys needed.
  • MIT. Read every line before it touches your inbox.
Install

Four commands.

Node 20 or later. Open localhost:4400, create your account, and start with sample data or your own keys.

Get Milo on GitHub

$ git clone https://github.com/kumarannathan/Milo.git
$ cd Milo && npm install
$ npm run build
$ npm start
