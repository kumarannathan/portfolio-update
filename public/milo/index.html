Approvals

Nothing gets sent until you approve it.

Each draft waits here next to the brief it came from. If you reject one, leave a note and the writer will use it next time. J K to move, A to approve, R to reject.

Logs

You can see what every agent did and what it cost.

Use the services you already have

Agents ask for an action like “find people” and you pick which service does it, such as Apollo, Hunter, Tavily, HubSpot or Cal.com.

A log for every run

Each run shows how long it took, how many tokens it used and what it cost. Each tool call shows its status code and latency.

Self-hosted

There's no Milo cloud.

Milo runs on your laptop or your own server, and your API keys stay there. Each key only goes to the service it's for. The browser only ever sees the last four characters.

Run it from source
$ git clone https://github.com/kumarannathan/Milo.git
$ cd Milo && npm install
$ npm run build
$ npm start
Milo is running at http://127.0.0.1:4400
$
Needs Node 20 or later. The server version has accounts, so a team can share one install.
