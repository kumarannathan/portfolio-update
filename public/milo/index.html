How it works

Work moves left to right.

Each agent hands off to the next through a task queue. You watch it happen, and you hold the send button.

01

Find and research

Scout finds companies that match your ideal customer. Researcher writes a brief with sources. Prospector finds the right people and verifies their email.

02

Score and write

Qualifier scores each lead and decides what happens next. Personalizer writes outreach from the brief, not a template.

03

You approve, SDR sends

Drafts wait in your inbox. Edit, approve or reject with a note the writer learns from. SDR sends, reads replies and books meetings.

Your keys, your server

Nothing goes anywhere you didn't connect.

Milo is one Node process you run yourself. There is no Milo cloud in the middle.

  • API keys are stored on your server, only sent to the service they belong to, and never returned to the browser in full.
  • Every account gets its own workspace. Sign in with email and password, or plug in Supabase Auth.
  • Export everything as JSON at any time. Keys are left out.
  • MIT licensed. Read every line before you trust it with your inbox.
Install

Four commands.

Requires Node 20 or later. Open http://localhost:4400, create your account, and start with sample data or your own keys.

$ git clone https://github.com/kumarannathan/Milo.git
$ cd Milo && npm install
$ npm run build
$ npm start
